# Контекст: работа над мясными карточками Абстрактных ингредиентов (HomeHarmony)

## 1. Правила оформления карточек

### 1.1. Общие правила (зафиксированы в проекте)

1. **`name`** — без буквы **Ё** (Свекла, Ежики, Топленое, Говяжья печень).
2. **`synonyms`** — с Ё-вариантами для поиска (свёкла, ёжики, печёнка, тушёнка).
3. **`name_normalized`** — транслит латиницей (`govyazhya_golyashka`, `tazobedrennyy_otrub_govyadiny`).
4. **`short_description`** — до 500 символов, для превью.
5. **`description`** — HTML с блоками:
   - `<h2 class="ingredient-title">Краткая характеристика</h2>` + `<p class="ingredient-text">`
   - `<h2 class="ingredient-title">Свойства и особенности</h2>` + `<ul class="ingredient-list ingredient-list-bulleted">`
   - `<h2 class="ingredient-title">Подготовка</h2>`
   - `<h2 class="ingredient-title">Кулинарное применение</h2>`
   - `<h2 class="ingredient-title">С чем сочетается</h2>`
   - `<h2 class="ingredient-title">Чем заменить</h2>`
   - Опционально: «Возможные варианты жирности» (для молочки), «Полезные ссылки», «Примечание по КБЖУ».
6. **`category`** — строка (например, «Мясо, птица, субпродукты», «Молоко, молочные продукты», «Жиры, масла, соусы, заправки»).
7. **`semantic_data`** — строго по схеме:
   - `properties` — массив строк
   - `preparations` — массив строк
   - `cooking_methods` — массив `{method, priority}` (priority: `high|medium|low`)
   - `applications` — массив строк
   - `pairings` — объект с ключами `protein`, `vegetables`, `sauces`, `herbs`, `spices`
   - `substitutes` — массив `{name, similarity}` (similarity: `high|medium|low`)
8. **`tags`** — массив строк, нижний регистр, **с пробелами, не snake_case**.
9. **Citation — ❌ никогда** (ни в `description`, ни в примечаниях).
10. **КБЖУ и нутриенты** — в отдельных полях, **только по явной просьбе**. В `description` не пишем.
11. **«Русский», не «россиянин»**.
12. **Команда импорта — после каждого файла: python manage.py import_ingredient semantic_data/abstractIngredients/<name_normalized>.json --force**

### 1.2. Правила работы с историческими названиями

- **Не переносить современные географические названия на исторические периоды.**
- Пример ошибки: «украинский сорт, выведенный в 1880-х» → правильно: «сорт, выведенный в 1880-х в питомнике Симиренко (Киевская губерния Российской империи)».

### 1.3. Формат упоминания иностранных названий

**Правило:** `EnglishName (Русское произношение)`.

Примеры:
- ✅ `Ribeye (Рибай)`
- ✅ `Filet Mignon (Филе-миньон)`
- ✅ `T-bone (Ти-боун)`
- ✅ `Porterhouse (Портерхаус)`
- ❌ `рибай` (без английского)
- ❌ `Ribeye` (без русского)

### 2.2. Как проставлять теги цвета

**Вручную через shell после импорта:**

```python
python manage.py shell -c "
from kitchen.models import AbstractIngredient, SemanticTag
i = AbstractIngredient.objects.get(name='Яблоко Гала')
tag = SemanticTag.objects.get(id=4583)  # красный
i.semantic_tags.add(tag)
print(f'{i.name}: id={i.id}, тег {tag.name} добавлен')
"
```

### 2.3. Проверка тегов
**Вручную через shell после импорта:**
```python
python manage.py shell -c "
from kitchen.models import AbstractIngredient
for i in AbstractIngredient.objects.filter(name__startswith='Яблок').order_by('id'):
    colors = [t.name for t in i.semantic_tags.filter(tag_type='color')]
    print(f'{i.id} | {i.name} | цвет: {colors if colors else \"—\"}')
"
```

## 7. Работа с массовыми позициями (яблоки, перцы)

### 7.1. Подход

Для продуктов с множеством сортов используем **базовые карточки по категориям** + **отдельные карточки сортов** с тегами.

**Пример (яблоки):**

- Базовые: Яблоко, Яблоко красное, Яблоко зелёное, Яблоко жёлтое
- Сорта: Гала, Ред Делишес, Фуджи, Гренни Смит, Голден Делишес, Антоновка, Семеренко, Макинтош, Айдаред, Хани Крисп, Роял Гала
- Каждый сорт имеет тег цвета (`color: красный/зелёный/жёлтый`)

### 7.2. Формат названий сортов

**Единственное число:** «Яблоко Гала», не «Яблоки Гала».

### 7.3. Формат названий цветовых карточек

**Строчная буква после «Яблоко»:** «Яблоко красное», «Яблоко зелёное», «Яблоко жёлтое».

```python
python manage.py shell -c "

    (5297, 'Яблоко Гала', 'yabloko_gala'),
    (5298, 'Яблоко Гренни Смит', 'yabloko_granni_smit'),
]
for id_, new_name, new_norm in renames:
    i = AbstractIngredient.objects.get(id=id_)
    old = i.name
    i.name = new_name
    i.name_normalized = new_norm
    i.save()
    print(f'{id_}: {old} → {i.name}')
"
```

## Правило: упоминание стейков в карточках

### Основное правило

**Все альтернативные названия стейков упоминаются на трёх уровнях:**

1. **В `description`** — чтобы Хозяйка видела альтернативы и могла выбрать.
2. **В `synonyms`** — для поиска.
3. **В `tags`** — для фильтрации и семантики.

**В `properties` (semantic_data)** — тоже дублируем альтернативы.

### Формат записи

**Основное название:** `EnglishName (Русское произношение)`.

**Альтернативы:** `EnglishName (Русское произношение)` — краткое пояснение (если нужно).

### Что пишем в `description`

Основное название — первым. Альтернативы — через запятую или списком, с пояснением, если это профессиональное/региональное название.

**Пример:**

> В стейковой культуре тонкий край известен как **Striploin (Стриплойн)**. К этому же отрубу относятся **Strip Steak (Стрип-стейк)** — американское название стейка, **New York Strip (Нью-Йорк Стрип)** — классический американский стейк, **Kansas City Strip (Канзас-Сити Стрип)** — стейк на кости, и **Club Steak (Клаб Стейк)** — стейк с костью.

### Правила транскрипции

- **Английское название** — в оригинале, с заглавной буквы.
- **Русское произношение** — в скобках, строчными, через дефис (если составное): `Стрип-стейк`, `Боун-ин Рибай`, `Нью-Йорк Стрип`.
- **Не используем Ё** в английских названиях и русском произношении.
- **Не используем транслит латиницей** в русском произношении (только кириллица).

### Почему так

**Strip Steak** и **Striploin** — это **разные английские названия**:
- `Strip Steak` — американское название **стейка** (готового куска).
- `Striploin` — ирландско-канадское название **отруба** (целой поясничной части).

В русском языке **«стриплойн»** закрепилось как торговое название **отруба**, а «стрип-стейк» — как калька. Поэтому основное название — `Striploin (Стриплойн)`, альтернатива — `Strip Steak (Стрип-стейк)`.
