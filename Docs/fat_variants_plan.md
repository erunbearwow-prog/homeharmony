# План: матрица жирностей (fat_variants) для продуктов с переменной жирностью

## 1. Проблема

Продукты типа творог, сметана, молоко, кефир, сливки, йогурт, ряженка имеют **переменную жирность**.
Если создавать отдельную карточку на каждое сочетание типа и жирности — получаем 5 × 5 = 25 карточек только для творога.

## 2. Решение

Один `AbstractIngredient` на **тип продукта** (Классический, Мягкий, Зерненый и т.д.).
Жирность — **не отдельная карточка**, а **вариация внутри карточки** через блок `fat_variants` в `semantic_data`.

## 3. Структура `fat_variants`

```json
"semantic_data": {
  "fat_variants": {
    "default": "5",
    "variants": {
      "0.1": {
        "label": "обезжиренный (0,1%)",
        "calories": 85,
        "protein": 18.0,
        "fat": 0.1,
        "carbohydrates": 1.5,
        "calcium": 120,
        "phosphorus": 220
      },
      "2": { ... },
      "5": { ... },
      "9": { ... },
      "18": { ... }
    }
  }
}
