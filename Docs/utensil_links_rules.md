# Правила создания ссылок на RecommendedUtensil в поле description модели CookingMethod

> Файл: `docs/utensil_links_rules.md`
> Область действия: словарь `METHODS` в `cooking/management/commands/update_cooking_methods.py`,
> поле `description` модели `CookingMethod`, рендер через `kitchen.utils.render_description`.

## 1. Назначение

Внутри описания метода можно поставить ссылку на запись справочника утвари
(`RecommendedUtensil`). При рендере маркер превращается в кликабельную ссылку,
а команда синхронизации автоматически создаёт M2M-связь «метод → утварь».

## 2. Формат маркера

    {утварь:Название|склонение}

- `Название` — точное название записи в справочнике `RecommendedUtensil`,
  совпадает посимвольно (регистр, пробелы, дефисы).
- `склонение` — форма названия для текста «внутри предложения»
  (родительный падеж и т. п.): `{утварь:Кухонный комбайн|комбайна}`.

Вторую часть можно опустить, если название в предложении стоит в именительном падеже:

    {утварь:Су-вид циркулятор}

## 3. Обязательные правила

1. **Название — только из справочника.** Название в маркере должно существовать в
   `RecommendedUtensil`. Команда `update_cooking_methods` проверяет каждое название
   и печатает warning, если записи нет. Связь на несуществующую утварь молча
   теряется (`.set()` пропускает незнакомые названия).
2. **Каждый маркер = связь.** Вся утварь, упомянутая маркером, попадает в
   `recommended_utensils` метода автоматически. Не дублируйте её в `METHOD_UTENSILS`.
3. **Явные связи — через METHOD_UTENSILS.** Утварь, которую не хочется превращать
   в inline-ссылку (мелкая, частая — «Лопатка», «Миска большая»), перечисляется
   в словаре `METHOD_UTENSILS` в конце файла. Оба канала объединяются через
   объединение множеств: дубли безопасны.
4. **Названия утвари вне маркеров — без ссылки.** Упоминание утвари обычным текстом
   (например, «куттером» в описании Эмульгирования) связи не создаёт и ссылкой
   не становится. Так помечаем понятия, у которых нет карточки.
5. **Склонение — обязательная часть маркера**, если название не в именительном
   падеже. Рендер подставляет склонённую форму в текст, а ведёт ссылку на карточку.

## 4. Правила выбора: маркер или METHOD_UTENSILS

| Ситуация | Решение |
|---|---|
| Утварь — «главный герой» метода (чем именно готовят) | Маркер в description |
| Утварь вспомогательная, ссылки не нужны (лопатка, миска) | METHOD_UTENSILS |
| Утварь упоминается в сравнении/от противного («не путать с …») | Обычный текст без маркера |
| Понятия нет в справочнике и карточка не нужна («куттер») | Обычный текст |

Ориентир: не более 2-3 маркеров на одно описание. Полный набор инструментов метода
в любом случае живёт в M2M — маркеры нужны там, где ссылка действительно полезна Хозяйке.

## 5. Переименования утвари

- Название справочника меняется в `update_recommended_utensils.py` (поле `name`),
  связи M2M переживают переименование (связаны по id).
- После переименования нужно поправить маркеры в `METHODS` на новое название —
  старое даст warning при прогоне.
- Переходный период: у записи утвари в `UTENSILS` указывается `former_names`,
  чтобы команда нашла старую запись (пример — «Блендер» → «Блендер стационарный»).

## 6. Запреты

- Нельзя ставить маркер на утварь, отсутствующую в справочнике.
- Нельзя вписывать в маркер склонение в первой части: `{утварь:комбайна}` — ошибка.
- Нельзя ссылаться маркером на записи-синонимы: «Куттер» — синоним, карточки нет,
  в тексте он остаётся обычным словом, а альтернативы перечислены в поле
  `alternative` карточек «Кухонный комбайн» и «Измельчитель кухонный».
- Нельзя держать одну и ту же утварь одновременно и маркером, и «обычным текстом»
  внутри одного предложения — выбирайте один способ.

## 7. Примеры

Корректно:

    Мелкое рубление продукта ножом, секачом или короткими импульсами
    {утварь:Кухонный комбайн|комбайна} или {утварь:Измельчитель кухонный|измельчителя}
    до мелких кусочков…

    Точная тепловая обработка продукта, запаянного в {утварь:Пакет вакуумный|вакуумный пакет},
    в водяной бане с {утварь:Су-вид циркулятор|циркулятором}…

Ошибочно:

    {утварь:Комбайн|комбайна}        # нет записи «Комбайн» — только «Кухонный комбайн»
    {утварь:куттера}                  # куттер — синоним, карточки нет
    {утварь:Блендер|блендером}        # запись переименована в «Блендер стационарный»

## 8. Чек-лист перед добавлением нового метода

1. Все ли inline-ссылки оформлены маркерами с верным склонением?
2. Все ли названия маркеров есть в справочнике (сверка с UTENSILS)?
3. Вспомогательная утварь вынесена в METHOD_UTENSILS?
4. Нет ли упоминаний карточной утвари «голым» текстом там, где нужна ссылка?
5. После прогона: warnings — ноль, связи метода соответствуют ожиданиям?
